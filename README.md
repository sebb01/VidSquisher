# VidSquisher
![Screenshot](screenshot.png)

VidSquisher is a simple GUI wrapper for FFmpeg for easily compressing videos to fit specific file size limits. Thanks to [BinaryCounter](https://github.com/binarycounter) for contribution to the backend.

## Build
Preferrably make and activate a Python venv before these steps.
```
pip install -r requirements.txt
.\package.bat
```
